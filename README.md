# Auto Typing Effect

A simple JavaScript project that creates a typing and deleting animation effect. Users can add their own words, and the animation restarts with the new word.

## Features
- Typing & deleting animation.
- Default words: `Developer`, `Student`, `Programmer`, `Designer`.
- Add new words via input field.
- Restarts animation when a new word is added.

## Usage
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Enter a word and click **"Click Me"**.
4. Watch the typing effect restart with your word.
